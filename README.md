# e-plantShopping
This repository contains the files for my Developing Front-End Apps with React course final on Coursera. 

Everything in this repository comes from either the original repository it was cloned from, instructions in the lab for what is needed, or my own mind.

The project is to create a fully functional e-commerce site for buying and selling various plants and sellers
It is to include a home page, a store page, a cart, and functioning buttons for adding to cart, removing from cart, viewing cart, clearing cart, and adjusting the quantities of items in cart.
It is also to include product images and descriptions. This project uses a fictional brand and company, and is designed to showcase my understanding of front-end development using react.
